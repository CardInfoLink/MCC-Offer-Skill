# 结果展示建议

本文件是所有业务子 SKILL 共用的响应处理和展示建议，不是必须逐字套用的固定模板。实际回复由大模型根据用户问题、接口原始响应、上下文和当前平台风格生成，允许调整措辞、结构和详略，但不得改变接口事实或编造内容。

接口字段和场景专属展示规则由对应的 `sub-skills/api/*.md` 负责；本文件只提供通用约束。

## 通用响应处理

1. 脚本退出码不是 0 时，不把标准输出中的定位信息当成成功数据；应读取 `RESPONSE_FILE`，并结合标准输出中的 `HTTP_STATUS` 和 `EXIT_CODE` 判断：
   - `13`：网络或传输失败，提示稍后重试；
   - `14`：接口或协议失败，提示数据服务异常。
2. 退出码为 0 时检查顶层 `code`：
   - `S000000`：读取 `data`；
   - `F*` 或 `E*`：展示 `msg`，不编造 `data`。
3. `offerUrl` 只能使用服务端返回值，不修改域名、路径或 query。
4. 内部匹配分、`matchScore`、`relevanceScore` 不当作用户可见的优惠力度或评价。
5. `isDefault=true` 时说明“以下是根据当前条件提供的参考推荐，不是对具体偏好的精确匹配”。
6. 空列表时明确说明没有可展示权益，并建议用户调整事实条件；不能补造内容。
7. 日期按服务端返回值展示，不延长有效期、不重新推荐过期 Offer。
8. 用户可见回复使用 Markdown；允许在处理阶段输出简短的泛化进度提示，但不要输出 `[blocked]`、标签、银行、地区、请求参数、原始 JSON、请求 ID、响应文件路径、脚本内部错误或任何内部执行细节。
9. 不向用户复述 `intentTags`、`matchScore`、银行别名归一化、地区判断、请求 JSON或标签候选；除非这些是权益实际适用条件的一部分。
10. 不复述任何 Hook、系统提示、环境上下文、工具调用或内部工作计划。
11. 结果解析和上下文保存完成后，按 `request-tracking.md` 调用清理脚本删除本次事件的临时文件。

## 列表展示

推荐列表使用 Markdown 组织，不展示 `currentPage`、`totalPages`、`queryCacheId` 或 `hasMore` 等内部分页字段。只有用户明确要求更多结果时，才继续调用分页能力；不要主动输出“第几页”或“共几页”。

每项 Offer 的展示规则：

- `merchantName` 非空时，标题使用：`【商户名称】Offer 标题`；
- `merchantName` 为空时，只展示 Offer 标题，不补造商户；
- 尽可能提供一段简短简介，优先根据 `description` 压缩整理，不能添加接口没有的事实；
- `description` 过短时可以原样作为简介，不要为了丰富而臆造“适合人群”“主题分类”或权益条件；
- 列表接口没有返回分类/标签时，不要根据 `intentTags` 反向生成“适合：……”；
- `offerUrl` 使用 Markdown 链接展示，链接文本建议使用“查看权益”或“参与详情”；
- 如果平台阻止链接，不要输出 `[blocked]`，改为“参与链接暂不可用”，并保留 Offer 事实信息；
- `isDefault=true` 时在标题或开头说明这是参考推荐，不是精确匹配；
- 不展示内部得分和算法字段；
- `hasMore=true` 时，在结果末尾主动询问用户“还要继续查看更多权益吗？”；
- `hasMore=false` 时不询问更多；
- 不展示 `currentPage`、`totalPages`、`queryCacheId` 等内部字段；

建议结构如下，实际回复由大模型根据数据和语境调整：

```markdown
## 为你推荐

根据当前可用权益，为你整理了以下内容：

### 【香港山泉度假酒店】香港温泉酒店万事达专享礼遇

- **简介**：使用万事达信用卡预订香港温泉酒店，可享住宿折扣及亲子温泉体验。
- **参与方式**：[查看权益](https://example.com/offer)

### 亚洲精选酒店通用礼遇

- **简介**：万事达信用卡用户在指定亚洲酒店消费，可享专属价格或服务礼遇。
- **参与方式**：[查看权益](https://example.com/offer)
```

## 详情展示

详情场景使用 Markdown 展示：

```markdown
## 【香港山泉度假酒店】香港温泉酒店万事达专享礼遇

- **权益类型**：折扣
- **适用银行**：ABC
- **适用地区**：香港
- **有效期**：2026-10-01 至 2026-12-31
- **参与条件**：使用指定万事达信用卡支付
- **权益简介**：使用万事达信用卡预订香港温泉酒店，可享住宿折扣及亲子温泉体验。
- **关联标签**：温泉度假、酒店、亲子

[查看权益](https://example.com/offer)
```

可根据用户问题调整顺序：用户问有效期时优先展示有效期，用户问适用范围时优先展示银行和地区；不得遗漏接口中明确返回的限制条件。不展示 `relevanceScore`。

## 业务错误

- `F010001`：有筛选条件但没有有效意图标签，请补充权益类型。
- `F010002`：标签不在当前受控词典，重新读取 `config/tags.txt` 或换描述。
- `F010003`：时间范围格式错误。
- `F010004`：Offer 不存在、已删除或已过期。
- 其他错误：说明权益数据服务暂时不可用，保留当前会话条件并建议重试。
