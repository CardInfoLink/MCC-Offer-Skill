# MCC Offer Skill 0.1.0

## 发布内容

- 统一 Skill 标识为 `mcc-offer-skill`。
- 提供通用 Agent Skills 包，以及 Claude Code、Cursor、OpenClaw、WorkBuddy 和 npm 分发结构。
- 提供 PowerShell/POSIX 隔离构建脚本和发布前验证入口。
- 提供 GitHub Actions 静态校验、Issue 模板和 Pull Request 模板。

## 获取与验证

主要分发方式是从 GitHub 的稳定分支或版本 Tag 直接发现 Skill。验收和 CI 执行仓库级静态检查：

```bash
sh tools/release/check.sh
```

```powershell
powershell -NoProfile -File tools\release\check.ps1
```

WorkBuddy ZIP、npm `.tgz` 和 GitHub Release 附件属于后续可选渠道，不是 GitHub 直接发现的必需步骤。发行内容不包含测试数据、运行时请求/响应、本地状态、`.kiro/` 或凭据。
